# SoilPlus — правила для Claude

Почвенный датчик на ESP32 (pH, TDS, влажность, температура) + веб-платформа
с ИИ-агрономом. Next.js 15 / React 19, Gemini 2.5 Flash, Supabase.
Прошивка: `firmware/soilplus/soilplus.ino`. Над репозиторием работают два человека
с разных ноутбуков — главная цель правил ниже: не ломать работу друг друга.

## Git: как работать, чтобы не было конфликтов

1. **Перед началом работы:** `git pull --rebase origin main`.
2. **Никогда не коммить напрямую в `main`.** Создавай ветку `имя/задача`
   (например `sultan/tds-fix`) и работай в ней.
3. Коммиты маленькие и по одной теме. **Пушь ветку в тот же день**, чтобы второй
   человек видел, что ты меняешь.
4. **В `main` вливать только после согласования с человеком.** Перед слиянием:
   `git pull --rebase origin main`, разреши конфликты, проверь, что сайт собирается.
5. **Никогда не делай `git push --force` в `main`.**
6. **При конфликте — остановись и спроси человека.** Не разрешай конфликт, просто
   выбрасывая чужие изменения.
7. **Не переформатируй файлы целиком** (prettier/eslint --fix по всему проекту) —
   это создаёт конфликты на каждой строке. Меняй только то, что нужно для задачи.
8. **Никогда не коммить:** `.env.local` и любые ключи, `node_modules/`, `.next/`, PDF.
9. Если меняешь общие константы — пины, Wi-Fi, калибровочные значения по умолчанию,
   `maxOutputTokens` — сначала скажи человеку и объясни зачем.

## Сайт

- Запуск: `npm install`, файл `.env.local` (5 ключей, их даёт Ерсултан), `npm run dev`.
- **Не запускай `npm run build`, пока работает `npm run dev`** — они затирают папку
  `.next`, и у сайта слетают все стили. Лечится: остановить dev, `rm -rf .next`, запустить.
- Проверка типов без сборки: `npx tsc --noEmit` (безопасно при работающем dev).
- У всех ИИ-маршрутов `maxOutputTokens: 8192`. **Не уменьшай:** модель тратит
  ~2.1–2.3k токенов на размышления, при меньшем лимите ответы обрываются, а прогноз
  урожая молча уходит на запасной алгоритм.
- `/chat`, `/irrigation`, `/connect` открыты без логина и не зависят от базы — так
  задумано, чтобы демо работало при уснувшем Supabase.
- Боевой сайт (https) к плате не подключится — браузер блокирует `ws://`.
  Демо с прибором только через `http://localhost:3000`.

## Прибор

| Датчик | Пин | Питание |
|---|---|---|
| pH (Po) | GPIO35 | 3V3 (не 5V — сожжёт вход) |
| TDS | GPIO32 | 3V3 |
| Влажность | GPIO33 | 3V3 |
| DS18B20 | GPIO4 | 3V3 + резистор 4.7 кОм между DATA и VCC |

Аналоговые датчики — только на ADC1 (32–39). Пины ADC2 не работают вместе с Wi-Fi.

**Чтение порта:** `PORT=$(ls /dev/cu.* | grep -E "usbserial|wchusb|SLAB" | head -1)`,
115200 бод, pyserial. Если открыт Serial Monitor Arduino IDE — он держит порт.

**Расшифровка симптомов:**
- `raw 4095 / 3.300 В` — нет сигнала или нет общей земли
- `raw 0 / 0.000 В` — земля есть, нет питания
- **все аналоговые разом на 0 или в потолке** — проблема в общем питании/земле,
  а не в датчиках. Проверяй мультиметром 3.3 В на шине
- датчик «шевелится» — **ещё не значит, что он работает**. Проверяй физикой (ниже)

**Функциональные проверки:**
- TDS: воздух ≈ 0 ppm → вода 100–400 → вода с солью резко вверх
- Влажность: воздух ≈ 0% → вода ≈ 100%
- pH: нейтральная вода ≈ 7
- TDS и pH **не ставить в одну воду** — TDS наводит на pH до 0.15 В (≈0.8 pH)

**Калибровка** хранится во флеш-памяти платы (команды в Serial: `cal show`, `cal ph7`,
`cal ph4`, `cal tds <ppm>`, `cal moistdry`, `cal moistwet`). **Не делай `cal reset`** —
сотрёшь калибровку, снятую вручную. `cal tds` — только по раствору с известным ppm.

**Wi-Fi логин и пароль — в `firmware/soilplus/secrets.h`**, он в `.gitignore`.
На новом ноутбуке: скопируй `secrets.example.h` → `secrets.h` и впиши хотспоты.
Можно указать до трёх сетей (`SOILPLUS_WIFI_SSID`, `_2`, `_3`) — плата подключится
к той, что рядом, поэтому каждый может показывать демо со своего телефона.
Без этого файла прошивка не скомпилируется. **Никогда не коммить `secrets.h`.**
После загрузки в Serial видно, к какой сети подключилась: `[WiFi] Connected to "..."`.

**Перепрошивка — только при крайней нужде.** Обязательно отключи ВСЕ датчики
(иначе GPIO2 подтянут и чип уходит в `boot:0xb` вместо режима загрузки),
закрой Serial Monitor, держи BOOT до `Writing...`.

## Известные проблемы (на 25.10.2026)

- **TDS под подозрением:** в воздухе показывал ~279 ppm, в воде ~223 — физически
  наоборот. Возможно, модуль повреждён реверсом полярности. Нужен тест с солью.
- Пороги засоления культур (`lib/crops.ts`) взяты из FAO (Paper 29 Table 4, Paper 61
  Annex 1). У тюльпана и саксаула данных FAO нет — значения оценочные, нужен источник.
- Пароль Wi-Fi, который был в прошивке до 25.10, остался в истории git (первый
  коммит). Убран из файлов, но его стоит сменить при следующей перепрошивке.

## Уже исправлено — не возвращать

- Формула полива: `V = ΔW × НВ × D × ρ × S × K_pH × K_EC`. Влажность и оптимумы культур —
  в % НВ, поэтому дефицит умножается на НВ (0.24). Без этого объём завышался в ~4 раза.
- Объём полива в чате считает `computeIrrigation`, модель только цитирует результат.
  Не возвращай расчёт литров в промпт модели.
