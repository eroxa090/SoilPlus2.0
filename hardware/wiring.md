# SoilPlus — схема соединений (для Cirkit Designer / Wokwi)

Собирать схему по этой таблице: каждая строка — один провод.
Пины датчиков, которые уже есть в прошивке, не менялись (pH 35, TDS 32, влажность 33, DS18B20 4).
Новые пины: BMP280, расходомер, насос, батарея.

## Питание

| От | К | Примечание |
|---|---|---|
| Аккумулятор 103450 «+» | TP4056 **B+** | **проверь полярность мультиметром до пайки** |
| Аккумулятор «−» | TP4056 **B−** | |
| TP4056 **OUT+** | тумблер KCD1, контакт 1 | |
| Тумблер, контакт 2 | MT3608 #1 **VIN+** и MT3608 #2 **VIN+** | |
| TP4056 **OUT−** | MT3608 #1 **VIN−**, MT3608 #2 **VIN−** — общая земля | |
| MT3608 #1 **VOUT+** (5.0 В) | ESP32 **5V/VIN** | выставить 5.0 В **до** подключения |
| MT3608 #1 VOUT+ / VOUT− | конденсатор 470 мкФ 10 В (+ / −) | у входа ESP32 |
| MT3608 #1 **VOUT−** | ESP32 **GND** | |
| MT3608 #2 **VOUT+** (5.0 В) | D4184 **VIN+** | только для насоса |
| MT3608 #2 VOUT+ / VOUT− | конденсатор 1000 мкФ 16 В (+ / −) | гасит пуск насоса |
| MT3608 #2 **VOUT−** | D4184 **VIN−** и общая земля | |

## Датчики (питание всех — 3V3 ESP32, земля — GND)

| Датчик | Сигнал | Пин ESP32 | Примечание |
|---|---|---|---|
| pH-4502C | Po | **GPIO35** | 3V3, не 5V |
| TDS v1.0 | A | **GPIO32** | |
| Влажность v1.2 | AOUT | **GPIO33** | |
| DS18B20 | DATA | **GPIO4** | резистор 4.7 кОм между DATA и 3V3 |
| BMP280 | SDA | **GPIO21** | I²C, адрес 0x76 (или 0x77) |
| BMP280 | SCL | **GPIO22** | |
| Батарея | средняя точка делителя 100к/100к (верх — на OUT+ после тумблера, низ — GND) | **GPIO34** | 4.2 В → 2.1 В |

## Полив

| От | К | Примечание |
|---|---|---|
| Расходомер YF-S401 красный | 5V (MT3608 #1) | |
| YF-S401 чёрный | GND | |
| YF-S401 жёлтый (сигнал) | делитель: 10 кОм к **GPIO27**, от GPIO27 20 кОм на GND | 5 В → 3.3 В |
| ESP32 **GPIO26** | D4184 **TRIG/PWM** | + резистор 10 кОм с GPIO26 на GND (насос не дёрнется при загрузке) |
| D4184 **OUT+ / OUT−** | насос + / − | |
| Насос + / − | диод 1N5819: катод (полоса) на «+», анод на «−» | если на D4184 своего диода нет |

## Где собрать схему онлайн

- **Cirkit Designer** (cirkitdesigner.com) — картинка проводов из модулей; для защиты и презентации.
- **Wokwi** (wokwi.com) — запускает прошивку на виртуальной ESP32; аналоговые датчики заменяются потенциометрами.
- **EasyEDA** (easyeda.com) — принципиальная схема, потом можно заказать свою плату вместо перфоплаты.
