# SoilPlus Mini — схема соединений

Каждая строка — один провод. Пины датчиков совпадают с прошивкой (pH 35, TDS 32, влажность 33, DS18B20 4).
Насоса и полива в этой версии нет: сколько поливать, считает сайт.

## Питание (задний ярус)

| От | К | Примечание |
|---|---|---|
| Аккумулятор 103450 «+» | TP4056 **B+** | **проверь полярность мультиметром до пайки** |
| Аккумулятор «−» | TP4056 **B−** | |
| TP4056 **OUT+** | тумблер KCD1, контакт 1 | |
| Тумблер, контакт 2 | MT3608 **VIN+** | |
| TP4056 **OUT−** | MT3608 **VIN−** — общая земля | **не B−!** На B− нет защиты |
| MT3608 **VOUT+** (5.0 В) | ESP32 **VIN** (через JST на перфоплату) | выставить 5.0 В **до** подключения |
| MT3608 **VOUT−** | ESP32 **GND** | |

## Перфоплата (передний ярус)

| От | К | Примечание |
|---|---|---|
| Конденсатор 470 мкФ 10 В «+» / «−» | ESP32 **VIN** / **GND** | полоса на корпусе = минус |
| Резистор 100 кОм | от тумблера (контакт 2) к **GPIO34** | делитель батареи: 4.2 В → 2.1 В |
| Резистор 100 кОм | от **GPIO34** к **GND** | |
| Конденсатор 100 нФ (по желанию) | **GPIO34** ↔ **GND** | показания батареи стабильнее |
| Резистор 4.7 кОм | **GPIO4** ↔ **3V3** | подтяжка DS18B20 |

## Датчики (питание всех — 3V3 ESP32, земля — GND)

| Датчик | Сигнал | Пин ESP32 | Где стоит |
|---|---|---|---|
| pH-4502C (электрод на BNC) | Po | **GPIO35** | плата справа на панели |
| TDS v1.0 (щуп в горловине) | A | **GPIO32** | плата слева на панели |
| Влажность v1.2 | AOUT | **GPIO33** | в горловине, разъём JST |
| DS18B20 | DATA | **GPIO4** | в горловине, разъём JST |
| BMP280 | SDA / SCL | **GPIO21 / GPIO22** | карман справа, Dupont 1×4 |

Аналоговые датчики — только на ADC1 (GPIO32–39): они работают вместе с Wi-Fi.
Ни один датчик не стоит на пинах загрузки (0, 2, 5, 12, 15).

## Перед пайкой и при включении

1. MT3608 выставить на **5.0 В** мультиметром **до** подключения ESP32.
2. Нагрузку брать только с **OUT+/OUT−** TP4056.
3. Прошивка по USB и зарядка — **с выключенным тумблером**.
4. Первое включение без датчиков: 5.0 В на VIN, 3.3 В на 3V3, ~2 В на GPIO34. Потом датчики по одному.
5. Разъёмы JST подписать: трёхконтактные у влажности и DS18B20 одинаковые.
