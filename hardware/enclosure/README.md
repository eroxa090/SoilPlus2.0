# Корпус SoilPlus — колышек (вариант В, лоток 1+2)

Модель полностью строится скриптом `soilplus_case.py` (Python + build123d).
Общие размеры (стенки, лоток, ярусы, отверстия, колышек) — в начале скрипта,
расположение гнёзд под модули — в `make_tray()` и `make_deck()`.
После любой правки перезапусти скрипт: он заново проверит зазоры.

```bash
pip install build123d
python soilplus_case.py
```

Скрипт:
1. строит 6 печатных деталей и макеты всех модулей;
2. проверяет, что ничто ни с чем не пересекается (должно быть «Пересечения: нет»);
3. проверяет, что каждая деталь влезает на стол 180 мм (Bambu A1 mini);
4. пишет файлы в `out/`.

## Файлы в `out/`

| Файл | Зачем |
|---|---|
| `SoilPlus_assembly.step` | **Открыть в Fusion**: File → Open → Open from my computer. Каждая деталь и каждый макет — отдельный компонент |
| `1_Head.stl` … `6_Water_Spike.stl` | Печать: уже повёрнуты так, как класть на стол, без поддержек |
| `viewer.html` | 3D-просмотр в браузере |
| `report.json` | Размеры деталей на столе, объём пластика, результат проверки |

## Детали

| # | Деталь | Как класть на стол |
|---|---|---|
| 1 | Голова | задней стенкой вниз |
| 2 | Лоток + передняя панель | полом вниз |
| 3 | Палуба (2 ярус) | плашмя |
| 4 | Колышек, передняя половина | плоскостью разъёма вниз |
| 5 | Колышек, задняя половина | плоскостью разъёма вниз |
| 6 | Игла полива | ёлочкой вниз, стоя |

PETG, слой 0.2, 6 периметров, заполнение 25–30 %.

## Что взято «на глаз» (замерить, когда придут детали)

| Параметр | Сейчас | Что это |
|---|---|---|
| ESP32 | 51.5 × 28.5 | ESP32 DevKit 30 pin Type-C; Type-C должен стоять на переднем краю перфоплаты |
| гнездо D4184 | 36 × 18 | рассчитано на большой вариант 35 × 16; маленький 23 × 16 тоже встанет |
| `KCD1_CUT` | 19.2 × 13.2 | вырез под тумблер (бывает 21 × 15) |
| `TDS_PROBE_D` | 12 | диаметр щупа TDS |
| `TUBE_OD` | 8 | наружный диаметр трубки |
| `INSERT_D` | 4.0 | отверстие под латунную вставку M3 |
